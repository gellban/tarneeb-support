# tarneeb-support

Support page for the **Tarneeb Master** iOS game, hosted via GitHub Pages.

## Live Site

Once GitHub Pages is enabled the site is available at:
`https://gellban.github.io/tarneeb-support/`

## How to Enable GitHub Pages

1. Open the repository on GitHub.
2. Click **Settings** (top menu).
3. In the left sidebar, click **Pages**.
4. Under **Source**, select the branch you want to publish from (e.g. `main`) and choose the `/ (root)` folder.
5. Click **Save**.
6. After a minute or two, GitHub will publish the site and show you the URL.
